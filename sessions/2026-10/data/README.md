# Dataset — October 2026

`dataset/` is the data exactly as HackerRank supplied it in their public starter repository,
`interviewstreet/hackerrank-orchestrate-october26`, where it was committed by HackerRank
staff between 19 and 25 October 2026. It is republished here unchanged for reproducibility.
The company, people and identifiers in it are fictional.

Contents:

| Path | What |
|---|---|
| `deletion_requests.csv` | the 518 requests to audit |
| `deletion_rules.csv` | retention and tombstone policy |
| `user_identities.csv`, `user_audit_log.csv`, `system_activity.csv` | identity and activity records |
| `evidence_files.csv` + `evidence/` | SQL dumps, logs, JSON, documents and screenshots referenced by the cases |
| `sample_output.csv`, `sample_deletion_requests.csv` | HackerRank's format examples |
| `output.csv` | HackerRank's placeholder output file |

Terms: HackerRank's. If HackerRank asks for it to be removed, it will be replaced by a
download script.
