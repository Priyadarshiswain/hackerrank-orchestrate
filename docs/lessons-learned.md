# Lessons learned across sessions

Cross-session synthesis only. Per-session detail stays in that session's notes and README.

## From October 2026

- Define what proves success before writing the fallback. The plan step let "no cited
  findings" mean `COMPLETE`, and the tests agreed with it.
- Tests must come from the requirements, not from the implementation they test.
- Where steps depend on each other, say so in the data. Sorting by name is not an order.
- A fixed sequence of LLM calls is a workflow, not an agent. Judges score the difference.
- Keep the reproducibility work (shipped caches, usage reports). It cost little and
  answered interview questions.
